# Decision: Auto-generation of Accredited Serial Number

## Context
When creating a new `Certification` record via the Filament admin panel, the application threw a `QueryException`:
`Field 'accredited_serial_number' doesn't have a default value`.

The `accredited_serial_number` field is required by the database schema (NOT NULL) but was neither provided by the Filament form nor auto-generated by the model.

## Decision
Implement auto-generation of the `accredited_serial_number` at the Eloquent model level using the `creating` event. This mirrors the existing, proven logic used for `document_code`.

The chosen format is `SN-YYYYMMDD-RANDOM6` (e.g., `SN-20260720-A1B2C3`). This ensures:
1. **Uniqueness & Safety**: The random suffix prevents race-condition collisions during concurrent record creation.
2. **Traceability**: The date prefix allows for easy visual sorting and filtering by creation date.
3. **Consistency**: Matches the existing architectural pattern used for `document_code`.

## Implementation
Updated `App\Models\Certification`:
- Added `generateAccreditedSerialNumber()` static method.
- Extended the `static::creating` hook to populate `accredited_serial_number` if it is empty or null.

## Consequences
- New certifications will always have a valid `accredited_serial_number` without requiring form input.
- No changes are required to the Filament form schema; the model handles it transparently.
- Existing records are unaffected.
- If a strictly sequential format (e.g., `ACC-2026-00001`) is required in the future, this method can be updated, though database-level locking or sequences would be needed to prevent concurrency gaps.
